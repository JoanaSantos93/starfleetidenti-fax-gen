# 🖖 Starfleet IDENTI-FAX Generator

A fun mini-project born out of pure Star Trek love! This is a compact, retro single-page web app (SPA) designed to generate TOS-era Starfleet security dossier cards and biometric passport fax prints. 

Whether you're creating custom crewmates, exploring bridge officer dossiers, or downloading personalized E-cards, this terminal has all the 23rd-century vibes covered.

---

### ✨ Features

* **📜 Interactive Telefax Cards:** Real-time updates for officer names, ranks, serial numbers, biometrics, and medical anomalies.
* **🧬 Procedural Biometrics:** Custom HTML5 Canvas dithering that generates procedural fingerprint stamps on the fly.
* **🎨 Retro Aesthetic & Themes:** 
  * Thermal Standard
  * Blueprint Mode
  * Matrix Visualizer
  * Vulcan Terminal
  * CRT Scanlines & Glitch background overlays
* **🔊 In-Universe Sound FX:** Built-in retro terminal beeps and transmission effects powered by the Web Audio API.
* **💾 Export & Share:**
  * **PNG Export:** Save crisp, high-res dossier images directly to your machine.
  * **URL Hash Links:** Share direct links to custom crewmate cards via URL parameter encoding.
  * **Physical Fax / Print:** Built-in printer-friendly output rules.
* **📂 Classified Dossiers:** Built-in presets for Enterprise officers (Spock, McCoy, Kirk, Scotty) and easter-egg Section 31 lore modals.

---

### 🛠️ Tech Stack

* **HTML5 & Vanilla JavaScript** (HTML5 Canvas, Web Audio API, URLSearchParams)
* **Tailwind CSS + Custom External CSS** (`SF-ID.css`)
* **Libraries:** [html2canvas](https://html2canvas.hertzen.com/) for PNG exports

---

### 🚀 Quick Start

No installation or build steps required! 

1. Clone or download this repo.
2. Open `index.html` directly in any modern browser.
3. Generate, customize, and transmit your dossier!
